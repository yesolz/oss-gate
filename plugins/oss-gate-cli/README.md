# OSS Gate CLI plugin

Generated by `scripts/build_cli_plugin.py` from `plugins/oss-gate`; edit the canonical source.

This package registers no MCP servers. Use its oss-review skill to collect evidence, write a narrative and render Korean or English reports through the local CLI. Run `cli.py --help` for commands.

Requires uv and Python 3.10+. DeepWiki is still external when called. Runtime dependencies include its MCP client library; no OSS Gate MCP server is started or registered by this package.
