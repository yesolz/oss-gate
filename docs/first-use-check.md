# First-use validation

Ask two or three people who have not used OSS Gate to try the following from the README. Record their actual client/OS/version and whether they used MCP or CLI. Do not supply the expected verdict or help before recording the point of confusion.

1. Install the plugin from the local candidate marketplace (or the public release after publication).
2. Ask for a review of a public package and exact version they understand.
3. Open the HTML, locate the main decision, and explain its reason in their own words.
4. Find an original source and identify one limit of the report.
5. Request the other language and confirm it uses the same evidence.

Record installation completion, time to first report, confusing step, generated files, and any factual inconsistency. Do not collect credentials or private package names. Use a redacted issue or local note. A maintainer's automated CLI run is not an external usability study. No external users were contacted or claimed by the local policy/3 implementation.
