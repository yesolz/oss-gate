# Python 웹 라이브러리 현황: 2026-11

자료 기준일: 2026-11-17 · 예제 개정: 정책 v2 · 검증: **WARN**

> 과거 정기 리포트를 공개용으로 개정한 예제다. 당시 목록에는 Flask와 Requests가 있었으나, 이 저장소에 Flask의 원본 스냅샷이 없다. 확인할 수 있는 한 건과 확인하지 못한 한 건을 분리하며 새 API 조회는 하지 않는다.

## 1. 요약

확인 가능한 스냅샷은 Requests 2.34.2 한 건이다. 정책 v2 재계산 결과는 가능 0, 조건부 1, 보류 0이다. 별도로 Flask 3.1.3 한 건은 근거 누락으로 집계에서 제외한다. Requests 스냅샷의 알려진 권고는 0건이며, 이는 누락된 Flask를 포함한 전체 목록이 안전하다는 뜻이 아니다.

Requests의 남은 도입 질문은 certifi@2026.10.23의 MPL-2.0이다. 실제 파일 수정과 배포 방식에 대한 사람의 검토가 필요하다. 이전 정기 리포트가 없어 변화량은 계산하지 않는다.

## 2. 대상과 범위

| 패키지 | 버전 | 현재 예제 판정 | 근거 | 상태 |
|---|---|---|---|---|
| pypi/requests | 2.34.2 | 조건부 | [data.json](../reviews/psf-requests-2.34.2/data.json) | 스냅샷 있음 |
| pypi/flask | 3.1.3 | 확인 필요 | 기존 문서의 언급만 남음 | 원본 누락, 집계 제외 |

과거 문서는 Flask의 itsdangerous@2.2.0과 jinja2@3.1.6을 `non-standard`로 분류했다고 적었다. 원본 JSON을 확인할 수 없으므로 해당 주장을 현재 집계나 독립적으로 검증된 사실로 사용하지 않는다.

## 3. 확인 가능한 결과

Requests의 직접 의존성은 4개, 간접 의존성은 0개다. 저장된 그래프는 잘리지 않았으며 대체 버전을 사용하지 않았다. certifi@2026.10.23은 MPL-2.0, charset-normalizer@3.5.2는 MIT, idna@3.20.0은 BSD-3-Clause, urllib3@2.8.0은 MIT다.

Scorecard는 8.2, 기준일은 2026-08-24다. 과거 검토일보다 85일 전이다. Flask 자료가 없으므로 이전 문서의 두 패키지 평균 7.65를 현재 검증된 평균으로 재사용하지 않는다.

검증 상태는 WARN이다. Requests의 저장 자료와 재계산은 확인할 수 있지만, Flask와 이전 비교 기간의 원본이 없다. 과거 문서의 PASS 표시는 이 개정 예제에 승계하지 않는다. 알려진 취약점 0건은 완전한 보안 보장이 아니며, DeepWiki 설명은 버전에 고정되지 않은 AI 생성 자료다.
