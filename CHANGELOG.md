# Changelog

## 0.6.0

- Add Java/Kotlin Maven resolved JSON trees and Gradle locks, including configuration provenance and exclusion of omitted verbose nodes.
- Add Swift Package.resolved versions 1/2/3 with OSV SwiftURL queries, explicit source/revision gaps and unsupported license metadata.
- Import native Trivy/Grype image reports offline, retain suppressed findings, bind Dockerfile/Compose references only by exact repository digest, and apply vulnerability/license policy with separate container counts and source hashes.

- Add Go module/workspace declaration screening and Cargo lock/workspace analysis. Preserve Go build-list uncertainty, custom/local source gaps, aliases, target/development groups and ecosystem-qualified identities through queries, policy and bilingual reports.
- Pin Tomli 2.5.0 for consistent bounded TOML parsing on Python 3.10 and later.

- Add offline local repository discovery and Yarn Berry workspace dependency screening through CLI and MCP, with exact-version deduplication, project occurrences and explicit unsupported-format gaps.
- Preserve repository input hashes and raw API evidence; generate scoped Korean/English dependency reports with vulnerability/license coverage and immutable evidence verification.
- Follow bounded OSV pagination for repository queries and apply identifier policy to single-query pagination requests. Require confirmed public identifiers or an explicit identifier allowlist before repository collection.
- Add a bounded string-only PyYAML loader; keep patched/Git/local dependencies, unresolved peers, manifest mismatches, caps and unavailable evidence visible.

## 0.5.0

- Preserve failed DeepWiki responses with tool-recorded capture metadata and index multiple topics without rewriting responses.
- Record agent checks through a validated local command with save time, evidence/narrative hashes and explicit archived replacement; reject stale checks.

- Add policy/3 license classifications, distinct uncertainty reasons and explicit OR choices using a pinned SPDX identifier catalog.
- Support optional license restrictions and attributed acceptance records without changing automated verdicts; reassess verified saved evidence offline into a new snapshot.
- Show actionable bilingual license findings, preserve reassessment provenance and handle equivalent PyPI versions consistently in dependency cards.
- Lead the README with real report screenshots and add a fresh bilingual allow example with raw evidence.

## 0.2.0

- Package OSS Gate for Claude Code and Codex with shared MCP, skills, policy and renderer.
- Replace the hosted review runtime with a read-only static demo; exclude the workshop deployment configuration from the public distribution and history.
- Add MIT licensing, source attribution, contribution/security guidance and release checks.
- Support Korean, English and both, with snapshot-preserving translation and bilingual historical examples.
- Capture original public API JSON and normalized evidence directly with integrity hashes and unique run directories.
- Compute verdicts in code and preserve missing, failed, capped and mismatched evidence as uncertainty.
- Stop treating version ranges as installed versions and fixed releases as remediation of an older vulnerable version.
- Harden license classification and escape report content; remove remote font dependencies and broad global hooks.
- Add offline regressions, MCP protocol/live checks, independent dependency auditing and static-distribution validation.

The revised examples do not alter their source JSON. FastAPI's substituted graph now limits its outcome to conditional; the missing Flask source is excluded from portfolio totals. This release does not certify the historical claims or retire any live cloud resources automatically.
